# Garran character reference pack

**Path in Life RPG repository:** `public/character-references/garran/`

- `master-sheet.png` — the approved composite character sheet (source image, unchanged).
- `appearance-specs.md` — appearance details, clothing, expressions, and mandatory consistency rules.

This is **reference material**, not a replacement for `public/portraits/garran.png`. No runtime paths, gameplay code, or story state need to change when this folder is added.

To install, extract the ZIP at the **root of the GitHub repository**, preserving folders. The resulting paths will be `public/character-references/garran/...`.
